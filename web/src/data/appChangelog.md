## \[v2.39.19] - 2026-11-16

> 新增 Gitee 国内镜像：用 Gitee 官方「仓库镜像管理」（Pull 方向）把 GitHub 仓库镜像到 Gitee，平时不自动同步，需要时用一条指令触发；另附本机一条命令的触发与校验脚本。

> Gitee 侧仓库只作镜像用，不要在 Gitee 上提交代码（会被下一次镜像覆盖）。

### Added

- 新增 Gitee 国内镜像配置指引（`docs/gitee-mirror-setup.md`）：后台配 Pull 方向镜像 + 一条 API 指令触发同步（`POST /api/v5/repos/:owner/:repo/remote_mirror/pull`）
- 新增 `scripts/sync_gitee_mirror.ps1`：一条命令完成触发同步（`Trigger`）、查镜像状态（`Status`）、比对两端 main（`Verify`）、建镜像配置（`CreateMirror`）、校验 GitHub 令牌（`CheckToken`）、推送式同步（`Push`）

### Fixed

- 播放页顶部导航行与「歌曲名 + 歌词来源」按钮行之间的空挡收窄，省出的高度还给歌词

- 遮罩型转场在末帧残留旧图：76 个效果逐个核对修正，3 个老效果一并补上；「十字擦除」恢复在电视上正常出现
- 「完整（FIT）」模式切到宽高比不同的图时旧图残留：转场结束后画面只剩新图
- 照片墙「重新扫描」扫不到照片：NAS 连接成功后自动扫描，设置页显示 NAS 来源状态
- 照片墙扫不到 NAS「家庭视频和照片」库里的照片：相册级回退生效，实测读到 20000 张并全屏渲染出真实照片
- 照片墙暂停时停在第一张不动：暂停状态也按设定时长正常换图
- 日志页的日志列表是独立滚动容器，滚日志时上方信息不动：改回随页面一起滚动
- 逐行模式歌词不跳行：逐行模式下歌词会逐行自动跳到当前行
- 设置页「标签 + 值」的值列过窄，长值被压成三行：改按 40%/60% 比例分配，所有设置页面长值一行显示（照片墙那行由 246px 变 772px）
- 切歌时通知封面不刷新：封面加载不再跨线程访问播放器，切歌时封面正常刷新
- 退出照片墙 / 切换画质档时日志里出现 `E PhotoBuffer decode failed for xxx.jpg: null`（`InterruptedException`）：这是 `close()` 中断在途解码的**预期取消**、结果本来就会被丢弃，改为 Debug 级记录；**真解码失败仍记 E**，不一刀切降级
- 天气刷新时日志里出现 `E WeatherApi getIpLocation failed ... SocketTimeoutException` 并带 20 行堆栈：ip-api.com 免费版仅 HTTP(80)、国内常年不可达，已有「回退北京坐标」兜底 ⇒ 降级为 W 级且不带堆栈
- 天气刷新不再为 IP 定位白等 10 秒：改用 3 秒短超时客户端，成功结果缓存 30 分钟、失败冷却 10 分钟（一轮刷新里的天气与预报不再各自重试一次）
- Open-Meteo 失败时天气不再直接放弃：失败只折算为空结果，继续走 OpenWeatherMap 兜底
- IP 定位缓存在并发刷新下仍会各发一次请求：读写与请求整段串行化，并做在途去重
- 高质量人声分离在一次播放服务 / 界面重建后永久卡在「分离中」且播放停在暂停：不再销毁 app 级单例的协程作用域，只取消在途的分离任务
- 洛雪脚本可让播放地址 302 跳到内网 / 云元数据地址并把响应回传脚本：出站请求与每一次重定向逐跳校验，脚本返回的播放直链统一过地址守卫
- 模型上传失败会删掉已装好的模型文件：改为先写临时文件、体积与校验和通过后才原子替换，失败只删临时文件；同时给上传体量加上限
- 下载任务崩溃后留下的半截音频被标成「已完成」且永不重下：只有磁盘长度与记录一致时才认作完成
- 飞牛曲库在服务端返回异常 total 时只加载第一页、统计显示「共 0 首」：total 无法解析时退回按页长度判断
- Jellyfin 响应里一条字段类型异常的记录会让整批歌曲变成空列表：逐条隔离解析，坏数据只丢自己
- 封面缓存重启后按哈希顺序淘汰、可能删掉刚解析到的封面：落盘时按真实写入时间排序
- 模糊搜索 / 换一批 / 清空在网络请求被取消时被当成失败上报：取消信号原样重抛，不再计入重试与错误日志
- 照片墙三个转场的末帧残留（过曝叠加 / 顶部暗条 / 黑色分格）：转场结束时只显示新图，停留期内也不再出现脏画面
- 海滨效果 HIGH 档的沙纹丢失：修正一处合批计数的笔误
- 歌词舞台换曲后可能沿用上一曲版面：把整曲世代号、画布尺寸与密度纳入重建判据
- 歌词分词丢弃 emoji / 组合字符 / 俄文等非中英文字符：改为按码点切分，中文仍保持逐字
- 混音节拍在「从未检测到节拍」时不进入兜底动画：修正兜底条件
- 歌词进度、列表项 key、封面轮播状态在切歌后的错位与崩溃：按审查结论逐处修正（列表 key 补 index、轮播状态随候选重置、进度参数下沉到叶子组件）
- 退出播放器时的兜底清理静默吞掉异常：改为记录 W 级日志，不再无痕

## \[v2.39.16] - 2026-11-09

> 全库代码审查（154 项发现：Critical 1 / High 13 / Medium 94 / Low 46）一次性落地。
> 逐条对照见 `docs/archive/NASMusicTV-代码审查报告-2026-11-09.html`。

### Fixed

- **Critical**：相册转场在 API < 26 上走 `clipPath` 会把硬件渲染进程打崩 —— 枚举层统一降级到 `CROSSFADE`，并新增门禁 `PhotoTransitionClipGateTest` 守住红线（改回 `clipPath` 立即变红）
- 固定转场档位绕过注册表导致黑屏：`effective()` 统一为两级降级（shader → clipPath）
- 相册墙扫描协程的异常被静默吞掉、失败后无法重试（`needScan` 永久丢失）
- 歌词换行把「上一首最后一行 → 下一首第一行」误判成同一行（整曲身份改用单调代数）
- 逐字歌词按 `String.length` 切分会把中文标点 / emoji / 组合字符从中间劈开（改按 code point 切分）
- 行时间戳相同或倒序时行时长为 0，逐字高亮第一帧就跳过整行（兜底最短行时长）
- B 站 MV 直链未做主机白名单：`playurl` 响应被投毒时可把播放器指向任意地址（含 `file://` 与内网）
- 百度网盘目录索引并发构建时重复整树遍历；MV 缓存导入不再无限量入表
- 模型下载的连接不关闭、进度回调每 64KB 抖一次 UI、取消后不复用
- 播放服务换封面时旧 `Bitmap` 不回收（native 内存泄漏）
- 备份恢复路径的数值字段（封面模糊半径 / 暗化 / 字号 / EQ 频段）遇 NaN / Inf 会让整份导入失败
- 百度 OAuth 的 `expires_in` 异常值与非字符串 `refresh_token` 会让刷新永久失败
- 飞牛登录日志打印 token 前缀、Jellyfin GBK 回退日志打印完整 URL（改为代数 / 脱敏）
- CI 打包工作流的密钥脱敏只覆盖 `storePassword`，`cryptoPassphrase` 会被明文打印
- 自定义弹窗未注册 BACK 处理器，遥控器返回键穿透到上一级导航
- `verticalScroll` 内嵌无界 `LazyColumn` 直接崩（日志设置页）；列表项补齐稳定 `key`
- 封面轮播在组合期调用外部回调（收敛到 `LaunchedEffect`）
- 均衡器 / 圆环 / 雷达网格等渲染器每帧新建 `Path` / `Stroke` / 数组；环形与回波线宽改为量化分桶预建

### Changed

- 播放页进度改为 `State` 下沉：每秒 tick 只重组进度条小节，不再重组整张播放页
- 设置页的模型下载进度四条流改为按分区条件订阅（不在「歌词 / K 歌」分区时不建流）
- 流派统计超过 8 类时合并为「其他（N 个流派）」，不再把整页撑长

- 「旷野公路」按所有者裁定**去掉天空侧全部雾化**：不再计算 `fogFactor` / 不再把颜色混向雾色，云纹直接铺到地平线与地形相接（地形那侧的雾不动）
- 「旷野公路」天空四边形外扩 8·ue → 64·ue：几何缝 3.9px → 0.65px，雾饱和点推到地平线附近
- 右下角景色组合标签追加构建标记 `·r4`：同版本号多次交付时，截图可直接核验装的是哪一轮包
- 「旷野公路」丘陵系列云层只剩**一层**：片元只采样上游世界坐标云 `vUUv`，不再采 `vUUUv`（那层被 `lowerScale` 压缩过、行驶时几乎不动，真机上就是「云层下方那块固定不变的云」）
- 「旷野公路」天空底色改为**天顶色平铺**：取消纵向渐变，一路铺到地平线；清屏色同步取同一个天顶色，天空平面够不到的缝露出来也是天空色
- 「旷野公路」新增**地平线裙边四边形**（同一套 uv、平面放到相机下方）：填满地平线以下、地形剪影之上的空档，云与天色在地平线两侧连续
- 「旷野公路」云层不再做任何雾化 / 淡出：不乘淡出系数、不算雾因子、不混雾色，云纹直接铺到地平线
- 右下角景色组合标签构建标记 `·r4` → `·r5`
- 右下角景色组合标签恢复为纯景色组合（`丘陵 · 夏季 · 晴朗 · 普通`）：按所有者定稿去掉 `·rXX` 构建轮次标记，`BUILD_TAG` 常量与两处拼接一并移除
- 「旷野公路」天空 program 清理**死 uniform**：删除雾色、两个雾距、两个云边淡出范围、远景云屏幕尺寸共 6 个已无人引用的 uniform（含句柄与上传）——第五轮重写后它们被 GLSL 编译器优化掉、`glGetUniformLocation` 恒返回 -1，那些上传一直是空操作

## \[v2.39.3] - 2026-10-20

### Fixed

- **修复飞牛音乐「全部歌曲」显示 0 首、搜索无结果**（后端为 fnOS 商店版飞牛音乐）：
  单条曲目的字段类型异常（如 CUE 分轨产生的 `duration:"154100.5"`、`album` 为字符串、`artists` 为单个对象）会让整页解析中断并被静默吞掉，导致服务端 1541 首却一首都不显示；改为**逐条隔离**，一条脏数据只丢它自己
- **修复歌曲列表加载失败时只显示「暂无歌曲」**：服务端返回错误码（如 `code=100005`）时界面不再静默，改为直接显示具体失败原因（含服务端 code/msg）并提供「重试」按钮，无需再靠日志排查
- **飞牛解析全面加固**：`album` / `artists` / `audioSpec` / `track` / `list` / `data` 等字段全部改用安全访问器，字段类型不符时降级而非抛异常；`duration` 支持数字、纯数字字符串与小数字符串（`"154100.5"` → 154100），无法解析时回退 0
- **修复「世界」3D 地球页面的 favicon 联网报错与日志刷屏**：WebView 自动请求的 favicon 是从虚拟资产域**根路径**发起的（不带 `/globe` 前缀），绕过了原有拦截，落到无公网 DNS 的保留域上产生 `ERR_NAME_NOT_RESOLVED` 错误日志；改为按 host 级拦截并在页面声明空 favicon，彻底离线
- **修复日志被「解密失败」告警刷屏**：多数后端没有 apiToken（百度未登录时 token 也是空串），每次读取凭据配置都会对空串/明文走一遍「全部密钥失败」并写入告警（告警始终落盘，会把崩溃现场从日志页挤掉）；改为空串与非密文形态直接透传，只有真密文解不开才告警
- **修复新装机后可能闪退（构造期竞态）**：「世界」地球/曲库的合并逻辑由构造期接线触发，会在主界面还没构造完时读尚未初始化的封面缓存字段，release 包上报 `NullPointerException` 闪退；已将相关缓存字段声明提前到构造最早期，并新增构造顺序门禁测试
- **修复网络音乐搜索/歌单空结果时日志被大量告警刷屏**：端点合法返回空列表（如某 Meting 端点持续回空数组）时不再按告警记录并落盘，只有端点返回无法识别的响应才留告警
